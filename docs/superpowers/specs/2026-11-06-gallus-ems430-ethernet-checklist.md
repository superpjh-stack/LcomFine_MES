# Gallus EMS430 Ethernet 연동 체크리스트

## 확인된 범위

- 장비: Gallus EMS430
- PLC: B&R X20 시리즈
- 내부 제어: POWERLINK
- I/O: X2X Link
- 외부 연동: Ethernet TCP/IP
- 읽기 가능한 후보: 인쇄 속도, 원단 장력, 인압 설정값, UV 출력값
- 추가 센서/연동 후보: 잉크 점도, 잉크 온도, 건조 온도
- 확장 후보: 인쇄 스테이션(색상 유닛)별 Register

## 장비 업체에 요청할 명세

1. 외부 TCP 서버의 IP와 포트
2. 연결 방향: MES가 장비로 접속하는지, 장비가 MES로 접속하는지
3. 프레임 형식과 요청·응답 예시(ASCII/Binary/JSON/고정 길이)
4. Register 주소·자료형·스케일·부호·바이트 순서
5. 색상 유닛별 Register 목록과 색상 매핑
6. 폴링 주기·연결 유지·재접속 규칙
7. 장비 운전/정지 상태와 생산 작업번호의 식별값
8. 테스트용 시뮬레이터 또는 현장 점검 시간

명세를 받기 전에는 임의의 payload를 전송하지 않는다. 현재 구현은 TCP 연결 확인과 읽기 전용 공통 모델·파서까지만 포함한다.
