# 엘컴화인 MES v2 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 새 기획서(2026-10-21)를 정본으로 대메뉴 17 · 화면 67 · 부서 8 의 LOT 단위 MES 를 다시 짓고, 출하 1건에서 원자재 LOT 까지 역추적되게 한다.

**Architecture:** 기존 FastAPI + Jinja2 + psycopg 골격(rbac · templating · nav · conn · audit · http · numbering)을 남기고 도메인(스키마 · 라우터 · 템플릿 · 시드 · 테스트)을 새로 쓴다. 정본 HTML → `contracts/ia.json`(+ `ia-overrides.json`) → `nav.py` · `function-list.md` · `permission-matrix.md` → 라우트 · 테스트가 게이트로 글자 단위로 이어진다. Phase 0(아키텍트) 뒤 4 웨이브를 개발 3 · QA 3 서브에이전트로 돌린다(goal.md 루프 프로토콜).

**Tech Stack:** Python 3.12 · uv · FastAPI · Jinja2 · psycopg 3 · PostgreSQL 17 · pytest · node(정본 추출 전용) · openpyxl(엑셀) · httpx(OpenAI REST) · Docker.

**Spec:** `docs/superpowers/specs/2026-10-21-mes-v2-design.md`

## Global Constraints

- 정본 `docs/엘컴화인_MES_기획서_2026-10-21.html` 은 고치거나 옮기지 않는다. 앱은 정본 · `ia.json` 을 읽지 않는다 — 게이트만 읽는다.
- 명령은 전부 `uv run …`. DB `lcomfine_db`(unix socket `/tmp`) · 포트 8020. 환경변수 접두 `LCOMFINE_`. 비밀은 `.env` 에만(G-21).
- 규모 기대값: 묶음 8 · 대메뉴 17 · 화면 67(정본 71 − RPT-090~120) · 부서 8 · 권한 칸 260(W 64 · R 196) · 채널 1 · 알림 9 · 흐름 띠 7.
- 이름(묶음 · 대메뉴 · 화면 · 부서)은 정본 글자 그대로. 대메뉴 RPT 만 이름 「대시보드」(D-505 · overrides).
- 라우터는 `app/routers/<l1 소문자>.py` 의 `router = APIRouter()`, `main.py` 는 아키텍트만. 경로는 `nav.path_of("WO-010")`.
- 쓰기 엔드포인트는 `rbac.require_fn("F-…")` 필수, 성공은 `http.saved(request, msg)` 직후 `audit.log_change(...)`. 입력 오류 422 · 없는 ID 404 · 미확정 501 `http.undecided("D-nn")`. 조용한 실패 금지.
- 번호는 `numbering.next(kind)` 한 곳, 알림은 `notify.emit` 한 곳, 집계 SQL 은 `dashboard` · `stats` 한 곳, AI 호출은 `ai` 한 곳.
- 조회 0건 `미수집` · 미확정 `미확정 (D-nn)` · 시드 `(예시)`. 고객명 · 품목명 · 채번 형식 · 산식을 지어내지 않는다.
- 기능마다 테스트 1 건 이상 `@pytest.mark.fn("F-WO-011")`. 테스트 삭제 · skip · 수치 하향 금지(옛 테스트는 D-503 으로 한 번에 삭제).
- 한 파일은 한 사람만(소유권 `contracts/screen-map.md` §3). 로컬 커밋만 · push · 배포 · 외부 전송 없음. 이 폴더 밖은 읽기만.

from tools import design_doc

def test_raw_matches_planning_doc():
    d = design_doc.load()

    assert (c["bundles"], c["menus"], c["screens"], c["roles"]) == (8, 17, 71, 8)
    assert (c["cells_w"], c["cells_r"]) == (76, 203)

def test_roles_equal_guide_page_ia_data():
    # 정본 2쪽(부서 간 업무 변화)의 IA_DATA 는 유효 권한을 JSON 으로 들고 있다 — 1쪽에서 계산한 값과 같아야 한다
