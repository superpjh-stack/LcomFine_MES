# 기능 목록 — 화면 기능 94 + 이관 배치 6 = 100줄 (아키텍트 · 2026-10-03)

> **이 표가 기능의 원본이다.** `src/lcomfine/app/contracts.py` 가 §2 의 표를 그대로 파싱해 placeholder 화면, `rbac.require_fn`,
> `tools/check_trace.py`(G-02) 에 준다. 표를 고치면 앱이 다음 기동부터 그 값을 쓴다 — 다른 곳에 같은 목록을 또 적지 않는다.
> **전개 전체가 `가설` 이다(D-09).** 설계도는 대메뉴별 수만 주었다. FP산정서 원본이 `docs/` 에 오면 이 파일을 그것으로 교체한다.

계보는 `lineage` 한 곳. 조회 화면은 0건일 때 `미수집` 을 보여 준다(G-11).
